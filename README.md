# API Demo Project (Node.js + Express)

This is a simple **REST API project** built using **Node.js + Express** to demonstrate core backend concepts such as:

- REST endpoints (GET, POST, PUT, DELETE)
- Request/Response handling
- JSON body parsing
- Basic validation and error handling
- Clean project structure (routes + controllers)
- Postman API testing

---

## 🚀 Tech Stack

- Node.js
- Express.js
- Postman (for API testing)

---

## ✅ Features

- ✅ Health check endpoint
- ✅ User CRUD APIs
- ✅ Search users by name using query parameter
- ✅ Proper HTTP status codes (200, 201, 400, 404)
- ✅ Clean architecture using routes + controllers
